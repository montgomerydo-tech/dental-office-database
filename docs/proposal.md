# Dental Office Appointment Management System

## Problem Description
Dental offices need an organized way to manage information about patients, employees, appointments, and dental services.

## Purpose of the database
The purpose of this database is to store and manage information about patients, dental employees, appointments, and services. It will help office staff easily find and update important information.

## Intended Users
The intended users are dentists, dental assistants, office managers, and front desk staff.

## Major Data That Must Be Stored
- Patient information
- Employee information
- Appointment dates and times
- Dental services
- Appointment status
- Dentist assigned to the appointment

  ## Questions the Database Should Answer
  1. What patients have appointments on a certain day?
  2. Which dentist is assigned to each appointment?
  3. What dental service is scheduled for each patient?
  4. How many appointments has each patient had?
  5. Which appointments are scheduled, completed, or canceled?
 
  ## Initial Business Rules
 1. Each patient must have a uniquepatient ID
 2. Each employee must have a unique employee ID.
 3. One patient can have multiple appointments.
 4. Each appointment must be connected to one patient.
 5. One dentist can be assigned to multiple appoointments.
